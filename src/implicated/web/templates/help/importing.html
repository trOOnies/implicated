🗄️ The library is the one source of truth. Small edits (a year, a rating, a new song) belong in the app. For bigger batches, like an artist's whole discography or a list of concerts, prepare files in the inbox, info/, and import them from the Import page (or make import). Nothing is imported on its own, not even when the server starts, so what you edit in the app always stays.

The inbox can hold a bands.yaml (artists, origin, genres, languages, a description, a Wikipedia link and members), plus bands/<artist>/albums.yaml (albums and their songs), bands/<artist>/band.jpg (a picture of the artist), bands/<artist>/covers/ (cover images, matched to albums by file name), bands/<artist>/songs/<song title>.txt (lyrics; a / in the title becomes _, and <>:"\|?* are left out), optional <song title>.lrc timed lyrics (a timestamp per line, like [01:23.40]Words) and bands/<artist>/tabs/ Guitar Pro files. A concerts.csv and tours.csv are added to yours, and a Download my data file named userdata.json brings back your marks.

🧩 Records are matched by their uid (exports carry one, so renamed records are still found) or else by name. A key in a file wins; a key left out keeps what you have, so a file only needs what it changes. Ratings, notes, favorites, CD and vinyl ownership, videos, listen later marks, playlists and plays are never touched by the YAML. Lyrics, timed lyrics and tabs are copied into the library's own folder (local/bands/), where the song page's buttons open them; an empty lyrics file in the inbox changes nothing. A broken file stops the whole import, and nothing changes.
