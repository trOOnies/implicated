🗄️ The library is the one source of truth. Small edits (a year, a rating, a new song) belong in the app. Files are for bigger batches, like an artist's whole discography or a list of concerts.

📬 The inbox

Prepare the files in the inbox, info/, then import them. Nothing is imported on its own, not even when the server starts, so what you edit in the app always stays.

📥 The Import page

  1. Put files in the inbox, or upload them on the Import page.
  2. See what they would change first.
  3. Press Accept (or run make import).
  • Accepted files move to an archive, so the inbox is empty again. Delete archives there once you no longer need them; you are asked first.
  • The page also downloads a backup or an export of your library.

🗂️ What goes in it

FileWhat it holds
bands.yamlArtists: origin, genres, languages, a description, a Wikipedia link and members
bands/<artist>/albums.yamlTheir albums and songs
bands/<artist>/band.jpgA picture of the artist
bands/<artist>/covers/Cover images, matched to albums by file name
bands/<artist>/songs/<song title>.txtLyrics
…/songs/<song title>.lrcTimed lyrics, optional: a timestamp per line, like [01:23.40]Words
bands/<artist>/tabs/Guitar Pro files
concerts.csv, tours.csvAdded to yours
userdata.jsonA Download my data file, bringing back your marks

💡 In lyrics file names, a / in the title becomes _, and <>:"\|?* are left out.

🧩 What changes

  • Records are matched by their uid (exports carry one, so renamed records are still found), or else by name.
  • A key in a file wins; a key left out keeps what you have, so a file only needs what it changes.
  • Ratings, notes, favorites, CD and vinyl ownership, videos, listen later marks, playlists and plays are never touched by the YAML.
  • Lyrics, timed lyrics and tabs are copied into the library's own folder (local/bands/), where the song page's buttons open them. An empty lyrics file in the inbox changes nothing.

⚠️ A broken file stops the whole import, and nothing changes. Fix it and preview again.
