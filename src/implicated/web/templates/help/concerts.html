Concerts you want to go to, are going to, or went to, upcoming ones first, with the band's picture. Open Concerts from the top bar.

📄 The concerts file

The concerts live in local/concerts.csv, next to the library, with the columns date;band;tour;country;city;Want to go;Going.

  • The page reads it every time it opens, so you can also edit the file and reload.
  • Everything you change on the page is saved there.

✅ Going or not

Set each concert to Want to go or Going. Once it is over, tick its Went box.

➕ Adding concerts

  • Add concert adds one to the file.
  • Add tour keeps a band's tour, so Add concert offers it for each of its dates.
  • The copy button at the end of a row fills Add concert with that concert: change what you need and add it.

📜 Setlists

A concert can have a Setlist: pick one of your playlists, holding the songs played there.

  • It is linked from the concert, and the playlist's page says which concerts it is the setlist of.
  • The file keeps the playlist's name in a Setlist column; renaming the playlist renames it there too.
  • A setlist goes into the Setlists folder by itself, and back to Default once no concert has it.
